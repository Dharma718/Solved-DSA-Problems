        ↓

# 🌐 Platform vs GitHub

This repository intentionally separates **platform activity** from **solution documentation**.

|                            | Coding Platform                       | GitHub                               |
| -------------------------- | ------------------------------------- | ------------------------------------ |
| **Purpose**                | Problem solving and submissions       | Solution documentation and portfolio |
| **Profile**                | Personal platform account             | Repository                           |
| **Statistics**             | Maintained by the respective platform | Not duplicated                       |
| **Submissions**            | Recorded by the respective platform   | Solutions documented                 |
| **Ratings / Achievements** | Maintained by the respective platform | Not duplicated                       |
| **Solutions**              | Submitted to the respective platform  | Organized and explained              |

### In short:

**Coding Platforms → Actual problem-solving activity**

**GitHub → Documented solution portfolio**

This prevents unnecessary duplication of information that is already dynamically maintained by each coding platform.

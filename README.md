# 🏆 Problem-Solving Approach

For every problem, the goal is not simply to find an accepted solution.

The focus is on understanding:

```text
Problem
   ↓
Understand Constraints
   ↓
Identify Observations
   ↓
Find a Suitable Approach
   ↓
Develop the Algorithm
   ↓
Implement the Solution
   ↓
Test with Examples
   ↓
Analyze Complexity
   ↓
Optimize When Possible
```

This approach helps develop the ability to recognize patterns and select appropriate algorithms rather than memorizing solutions.

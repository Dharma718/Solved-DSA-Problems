# 🔍 Problem-Solving Methodology

My general approach to solving DSA problems follows this process:

```text
Understand the Problem
        ↓
Analyze the Constraints
        ↓
Identify Key Observations
        ↓
Recognize Possible Patterns
        ↓
Choose Appropriate Data Structures
        ↓
Design the Algorithm
        ↓
Implement the Solution
        ↓
Test Edge Cases
        ↓
Analyze Time & Space Complexity
        ↓
Optimize When Possible
```

This process helps develop the ability to approach unfamiliar problems systematically rather than relying only on memorized solutions.
